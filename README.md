# E-Commerce Sales Analytics

A beginner-friendly portfolio project for exploring synthetic e-commerce sales data using Python and an interactive Streamlit dashboard. The project includes data generation, cleaning, exploratory analysis, SQL queries, and a local dashboard for interactive exploration.

---

## Project overview

This project demonstrates a complete, reproducible workflow for small-scale e-commerce sales analysis: generating a synthetic dataset, cleaning and validating it, performing exploratory analysis and visualizations, and presenting results in an interactive Streamlit dashboard.

This repository is intended for learning and portfolio use only. The dataset is synthetic (generated by the project) and does not contain real customer or company information.

---

## Business problem and objectives

Business problem
- Provide simple analytics to understand sales performance across products, categories, regions, and time.

Project objectives
- Generate a reproducible synthetic e-commerce dataset for analysis.
- Clean and validate the dataset to ensure basic data quality.
- Calculate business KPIs (revenue, orders, units sold, average order value) and answer common business questions.
- Create visualizations and an interactive dashboard to explore trends and top-performing products.

## Dataset details

- The dataset used in this project is synthetic and generated by the included generator script. It is intended for learning and portfolio demonstration only.
- Typical columns generated or expected include: `Order_ID`, `Order_Date`, `Customer_ID`, `Product`, `Category`, `Quantity`, `Unit_Price`, `Discount`, `Sales`, `Payment_Method`, `Region`.
- The cleaning script (`src/clean_data.py`) performs type conversions, flags and/or removes exact duplicates, validates `Order_Date`, numeric columns, and checks that `Sales` matches the documented calculation.

## Key metrics and business questions

The project computes or supports analysis for these common sales metrics and questions:
- Total revenue, total orders, and total units sold
- Average Order Value (AOV)
- Revenue by product, category, and region
- Monthly revenue trends and month-over-month change

## Setup instructions (Windows + VS Code)

1. Clone the repository and open it in VS Code.
2. Open the integrated terminal in VS Code (Terminal → New Terminal).
3. Create and activate a Python virtual environment (recommended):

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

macOS / Linux (for reference):

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

4. Confirm the required packages are installed (`pandas`, `numpy`, `plotly`, `streamlit`, `matplotlib`). See `requirements.txt`.

## Scripts and the correct run order

Run these scripts from the project root. Only scripts that exist in the repository are listed.

1. Generate the synthetic dataset (if you want to regenerate it):
   - Primary (src/):
     ```bash
     python src/generate_dataset.py
     ```
   - Alternate (root) if present:
     ```bash
     python generate_dataset.py
     ```
   The generator writes a CSV (commonly `data/ecommerce_sales.csv` or `ecommerce_sales.csv` at the repo root).

2. Clean the dataset (produces the cleaned CSV expected by analysis and the dashboard):
   ```bash
   python src/clean_data.py
   ```
   This script saves `data/ecommerce_sales_cleaned.csv` (and may also save an audit file `data/dropped_duplicate_order_ids.csv`). If the script cannot find a raw CSV, it prints instructions.

3. Exploratory analysis (static charts and CSV outputs):
   ```bash
   python src/analyze_sales.py
   ```
   This reads the cleaned CSV (or falls back to the raw CSV if a cleaned file is not present), produces charts in `outputs/charts/` and saves grouped CSVs to `outputs/`.

4. Launch the interactive Streamlit dashboard:
   ```bash
   python -m streamlit run app.py
   ```
   The dashboard expects the cleaned CSV at `data/ecommerce_sales_cleaned.csv` (it will fall back to `data/ecommerce_sales.csv` or repo-root CSV filenames if present). If the cleaned file is missing, the app will display a helpful error instructing you to run the cleaning script first.

## Limitations

- The dataset is synthetic and intended for demonstration only — results do not reflect a real business.
- Some files in this repository were generated as outputs (HTML charts, JSON reports). Decide whether to keep these binary outputs in the repo or recreate them from the analysis scripts when needed.
- The cleaning script currently keeps flagged rows and adds issue columns rather than automatically deleting; further manual review may be needed for production use.
- The current dashboard reads data from a local CSV. For a deployed dashboard you would typically use a database or storage layer.
